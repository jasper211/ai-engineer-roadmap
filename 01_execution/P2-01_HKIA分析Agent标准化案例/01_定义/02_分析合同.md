# G1-02 HKIA 代理渠道分析合同 v0.1

> 状态：待数据资产核对后签核。合同未签核前，所有数字和标题只能视为工作假设。

## 1. Baseline 八字段

| 字段 | v0.1 约定 | 待核对项 |
|---|---|---|
| 起点 | 2019 FY / Q4 累计 | 数据中的年度标识 |
| 终点 | 2025 FY / Q4 累计 | 是否为最新完整年度 |
| 频率 | 完整年度主线 | 年度事实表覆盖 |
| 同期规则 | 2026 Q1 仅对 2025 Q1 YTD | 季度字段和发布日期 |
| 对象集 | 香港新造个人长期险业务 | HKIA 原表的对象定义 |
| 分母 | 同期、同对象、同口径市场总额 | 官方市场链/公司加总链归属 |
| 口径 | NOP 与 APE 并列 | 公式、单位和源字段 |
| 断点 | 2024 年监管表式/RBC 变化保留双链 | 断点影响范围与差异率 |

## 2. 分析继承链

```text
L0 数据底座与颗粒度
→ L1 时间合同 + 口径合同
→ L2 主维度：渠道
→ L3 公司单维落点（按需）
→ L5 主题页面：代理规模增长但份额下降
```

低层合同优先。主题表达不得要求数据生成不存在的公司多维立方。

## 3. 指标合同

| 指标 | 公式 | 业务含义 | 禁止误读 |
|---|---|---|---|
| NOP | annualized + single | 新造现金规模 | 不等于经济价值 |
| APE | annualized + 10% × single | 持续化价值代理 | 不等于利润、EV 或资本回报 |
| 市场份额 | 渠道金额 ÷ 同口径市场总额 | 相对竞争位置 | 不得混用分母 |
| 净增量 | 终点 - 起点 | Baseline 下的绝对变化 | 不得省略起止期 |
| 增量贡献率 | 渠道净增量 ÷ 市场总净增量 | 增量在互斥渠道间的分配 | 跨维度贡献率不得相加 |
| 件均 | 保费或 APE ÷ 保单数 | 量价结构 | 不等于客户价值或利润 |

## 4. 维度与颗粒度

- 主维度：渠道。
- 平行验证维度：缴费方式、产品、货币；每条证据分别回加总。
- 公司层：只使用公开事实支持的单维金额、份额、增量和 Peer 比较。
- 市场二维：只在真实事实表白名单内使用。
- 禁止：由“产品 × 渠道”和“产品 × 货币”推断“产品 × 渠道 × 货币”。

## 5. 固定样本与动态样本

- 固定样本：回答 2019 年同一批代理主导公司到 2025 年如何变化。
- 动态样本：回答 2025 年当期代理主导公司版图。
- 两者差异：解释成员跃迁效应，不得混称为经营改善或恶化。
