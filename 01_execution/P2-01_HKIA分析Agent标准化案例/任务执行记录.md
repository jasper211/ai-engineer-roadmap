## 一、规划

### 1.1 目标

- 业务侧：完成“代理绝对增长但份额下降意味着什么”的一页论证。
- 方法侧：让 Jasper 能复述并亲自执行老板的七步分析动作链。
- 工程侧：建立未来分析 Agent 的状态机、阶段门、输入输出和异常检测。

### 1.2 范围

- **包含**：2019—2025 完整年度主线；NOP/APE；渠道；必要的公司单维落点；2026 Q1 仅作同季验证。
- **暂不包含**：客户动机、代理生产率、佣金激励、利润与资本效率的确定性结论。
- **数据边界**：只使用真实存在且通过审计的事实表；不从多个二维表拼造三维事实。

### 1.3 关键步骤

1. G1：锁定决策问题和分析合同。
2. G2：盘点事实表、字段、公式、分母和监管断点。
3. G3：完成结构、趋势、比率及边际贡献分析。
4. G4：压缩为一页并逐项验收。
5. G5：复盘人机分工，形成方法论转正候选。

### 1.4 关键风险

| 风险 | 影响 | 控制 |
|---|---|---|
| 把知识库目录当成分析流程 | 产物很多但问题未回答 | 以 Gate 驱动，不按目录填空 |
| 先画图后定义问题 | 数据可得性替代业务重要性 | G1 未通过不得进入制图 |
| 2024 监管表式断点被忽略 | 跨期变化被错误归因为经营变化 | 官方市场链与公司加总链并列审计 |
| NOP 增长被直接解释为价值增长 | 结论越界 | 核心结论默认 NOP/APE 并列 |
| 多个二维表被拼成伪三维 | 制造不存在的数据事实 | 只做平行证据，不恢复联合分布 |
| Agent 自动生成强因果语言 | 公开事实被越级解释 | A/B/C 语言权限和人工 Gate |

### 首轮方法论观察

- 确定性数据聚合可以较快达到高质量，尤其是金额、份额、增量贡献和双口径比较。
- 最大风险来自口径识别和呈现转换，而不是算术：新旧 schema、整付字段歧义、百分比数据类型都曾造成错误或险情。
- 没有老板行业经验库时，分析仍可稳定达到“事实诊断层”；从结构事实跳到客户动机、渠道能力和利润结果时会出现明显证据缺口。
- 更重要的过程偏差：AI在得到三份材料后过早追求报告结果，没有先建立多源输入、证据治理、完整分析框架和Agent协作结构。此偏差已记录为后续 Reviewer 的异常模式：`premature_delivery_before_framework`。
