# 09 测试与调试

## 测试范围

当前自动化测试覆盖：

- 文件变化检测和失败状态保护；
- 证据 ID、派生规则和快照 Hash 的确定性；
- PostgreSQL 只读边界；
- OB 待复核材料排除；
- Gate M/E/A 判断；
- 蓝图多种真实结构解析且不补造映射；
- D1–D6 和 Skill 二次评估的来源保留；
- 所有 L3 使用相同分析契约；
- 分析包准备、过期拦截、证据校验和发布；
- 分析模块修复和单批 L4 刷新；
- 分析包优先于 reviewed 兼容层。
- 源头新增 L4 后，旧分析包保留审计信息但不再填充当前页面。

## 运行

```bash
python3 -m unittest discover \
  -s 09_测试与调试_Test_and_Debug/tests -v
```

前端同时执行：

```bash
cd 10_部署与运行_Deploy_and_Run/frontend
npm run build
```

## 回归样本

第一阶段封版至少抽查：

- `L3-COM`：复杂流程与多轮业务校准；
- `L3-IRI`：流程结构和页面基线；
- `L3-IBRD`：人工控制和判断链；
- `L3-HRA`、`L3-HRM`：跨业务域一致性；
- 一个 Gate M 不通过的反例。

测试通过不等于业务内容已确认。模型分析包仍需检查证据是否真正支持其文字结论。
当前复核队列见 `L3模型复核队列_20260802.md`。
