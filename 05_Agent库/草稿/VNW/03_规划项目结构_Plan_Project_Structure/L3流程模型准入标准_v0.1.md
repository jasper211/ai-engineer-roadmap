# L3流程模型准入标准 v0.1

> 宗旨：缺少流程骨架和任务依据时不生成模型；少量非关键缺口不阻断建模；AI建设条件不足不影响流程模型本身。

## 1. Gate M：模型准入硬门

以下检查必须全部通过：

1. 数据库存在L4，且L4编码、中文名称完整；
2. 存在能够解析出步骤的正式流程蓝图；
3. 交付物覆盖率不低于70%；
4. 当前L3全部L4均具备D1-D6；

任一项不通过时，状态为`WAITING_INPUT`，系统不创建模型运行包、不调用模型，
首页显示具体补建项。

## 2. Gate E：证据充分度门

完整模型门槛：

- 交付物覆盖率不低于90%；
- 可追溯任务覆盖率不低于80%；
- 关键L4任务覆盖率100%；
- 存在价值节点与L4映射；
- 规则至少能够定位到一个当前L3的L4；
- Tier全部合法。
- 存在能够定位到真实文件的SOP草稿或同等任务执行材料；
- 存在能够通过价值节点关联到本L3的规则记录。

带缺口模型最低门槛为Gate M通过。SOP、规则、任务覆盖率、价值节点映射等不足
必须显示为待完善项，但不阻断流程模型搭建。规则用于补充任务约束与人机协同分析，
其持续优化不应让流程模型失去准入资格。

状态：

- `PASS`：`FULL_MODEL`，允许生成完整模型；
- `CONDITIONAL`：`LIMITED_MODEL`，允许生成带明确缺口的模型；
- `BLOCKED`：`WAITING_INPUT`，不生成模型。

## 3. Gate A：AI建设准入门

Gate A不作为流程模型生成前提。它继续检查：

- Gate E至少达到`CONDITIONAL`；
- D1-D6是否完整；
- 是否存在价值节点映射；
- 是否存在熔断或无价值节点。

Gate A阻断表示暂不进入AIT建设，不表示流程不值得建模。

## 4. 当前正式输入

- 流程蓝图：EA项目L3流程库中能够解析的实际Markdown文件；
- SOP：`T19_SOP生产进度_全域_v2.0.csv`中登记且磁盘文件真实存在的材料；
- 规则：`T5_规则清单_全域_v3.0.csv`中具有规则ID、价值节点和规则动作的记录；
- L3/L4、交付物、Tier、价值节点映射：`process_analytics`只读数据库；
- D1-D6：数据库事实或已确认的全量两阶段复核表。

仅文件名相似、文件不存在、无法关联当前L3或状态不明确的材料不计入准入。

## 5. 页面行为

- `FULL_MODEL`：可进入完整模型；
- `LIMITED_MODEL`：可进入模型，但必须显示局部缺口；
- `WAITING_INPUT`：缺少可解析蓝图、有效L4、基本交付物或完整D1-D6时，首页显示待补项并关闭模型入口。
