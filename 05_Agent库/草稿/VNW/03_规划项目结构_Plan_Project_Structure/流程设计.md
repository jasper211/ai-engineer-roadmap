# VNW v0.1 最小闭环流程

`发现最新清单 → SHA-256 与成功状态比对 → 有变化则调用 Phase1 信号提取器 → 校验 Markdown 产物存在 → 原子写入状态`。

失败发生在状态提交之前，因此下一次运行仍会重试。源清单只读，状态和产物只进入 `.vnw_workspace/` 或用户指定的 `--workspace`。

## 数据表链路（2026-07-25 补充）

01-04 层的实际产出链路是 `价值节点清单 → 信号提取基线(02) → 访谈准备与执行/规则空白地图+熔断节点补建清单(03) → 规则与GAP产出(04) → SOP(05)`，这条链路当前由 `sync_data_foundation.py` 一键全量重建为 23 张结构化数据表（A/C/D 三类，详见 [README.md](../README.md)）。

在 SOP 之后新增了一层**展示层**：前端 `app_v2` 直接读数据底座导出的 JSON，把节点、规则、Gap、熔断状态、SOP 生产进度、候选 Agent 归属等表可视化，作为跟负责人沟通规则、判断"哪些该自动化"的工作界面，不是独立的新流程分支，而是 05 之后同一条链路的呈现方式。
