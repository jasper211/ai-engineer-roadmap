# AIT 第一批试点规划（2026-07-30）

## 一、现状同步

VNW 进入新里程碑，根 README 升到 v0.6.0，明确三阶段边界：
- **第一阶段（进行中）**：为全部合格 L3 分批运行统一分析、执行证据抽检和跨域回归，完成后封版
- **第二阶段（未启动）**：源头自动更新
- **第三阶段（未启动）**：交互写回

分析管道本身也升级了——不再只是"读数据库拼快照"，每个 L3 现在多了一层 `analysis` 字段：由 `deepseek-v4-pro` 按固定标准（`VNW-L3-COM-GOLD-v1.0`，即把 L3-COM 那版人工深度 demo 当作生成标准）自动产出 task 拆解（建议 Tier + 理由）、priority_draft（数据依据 + 风险 + 建议）、decision_draft，部分 L3 还有 control_chain（强制关卡链）。这一层填补了之前"机械骨架"和"人工深度 demo"之间的空白。

**就绪度分级**：`model_readiness.status` 按交付物/任务/规则/关键 L4/Skill 可行性覆盖率门槛，分 WAITING_INPUT / LIMITED_MODEL / FULL_MODEL 三档，决定"数据够不够生成分析"；`production_status` 另外跟踪"分析是不是真的跑过、跑的是不是最新输入"，两者不是一回事。

**真实统计（67 个 L3）**：
- FULL_MODEL = 5：L3-COM / L3-HRA / L3-HRM / L3-IBRD / L3-SPE
- 但 L3-SPE 的 `production_status=RUN_PREPARED`——分析排队中但还没真正跑，现在挂着的 3 条任务是旧数据（Tier 字段是空的），**不能当真实结果用**
- 真正可信的只有两档：
  - **REVIEWED（人工复核过）**：L3-COM（18 L4/49 任务）、L3-BAM（11 L4/38 任务，LIMITED_MODEL 但已复核）
  - **MODEL_DRAFT（LLM 刚生成，未经人工复核）**：L3-HRA（7 L4/13 任务）、L3-HRM（9 L4/27 任务）、L3-IBRD（8 L4/12 任务）、L3-IRI（LIMITED_MODEL）
- 其余 53 个 L3 是 READY_TO_RUN（够格但还没排上批跑），4 个 BLOCKED_INPUT（数据不够，进不了模型）

## 二、AIT 第一批候选任务规划

**分组原则**：不是"谁是 FULL_MODEL 谁先上"，而是按"分析结果可信度"分组——REVIEWED 优先于 MODEL_DRAFT 优先于排队中。资金安全强制关卡和物理执行类 L4，无论建议 Tier 多高，永远不进"可全自动"候选池。

### 组 1：可以现在就进 AIT 设计（REVIEWED + Auto + 非关卡 L4）

**L3-COM**（22 条）：02-c 历史数据三年全量迁移、03-a/b 整合应派数据与生成外发凭证、05-a/b 退保识别与倒扣计算、06-a/b 税务规则匹配与处理记录、08-a 跨保司佣金汇集、09-a 佣金异常扫描、10-a/b 保单整合与应收计算、11-a/b 银行流水提取与实收匹配、12-b/c/d 应派计算/渠道对账/IA阈值预检、15-a/b 付款回执归档与台账更新、16-b/c 字段抽取与结构校验、17-a/b IA合规阈值计算与硬拦截

**L3-BAM**（14 条）：03-a/b U盾登记与双签核验、04-a~d 月度对账单监控/识别/更新/分发、05-a/b 缺失清单与催办计划、07-a/b 账户状态汇集与异常识别、09-a/b 银行费用汇总与年检监控、11-a/b 档案归集与索引生成

共 **36 条**真实、经过人工复核的 Auto 任务，这是 AIT 第一批的实际候选池。

### 组 2：LLM 草稿已生成，建议人工复核后再排期

L3-HRA / L3-HRM / L3-IBRD / L3-IRI 里建议 Tier 为 Auto 的任务，先走一遍 COM 当初走过的人工复核流程（读蓝图 + 数据库 + OB 交叉验证），复核通过后并入组 1。注意 L3-IBRD 的任务分布明显偏 Hybrid/Human（Auto 只有 1 条），本身自动化空间就小，复核时不用强求。

### 组 3：暂不进 AIT

L3-SPE（分析还没真正跑，等第一阶段批跑推进到它）；其余 53 个 READY_TO_RUN（还没排上分析）；4 个 BLOCKED_INPUT（数据不够）。

## 三、强制关卡规则（无论 Tier 多高都不能全自动）

- **资金安全强制关卡**：L4-COM-13、L4-COM-14、L4-BAM-10
- **物理执行类**：L4-BAM-02、L4-BAM-08、L4-HRM-05

这些 L4 下的任务必须保留人工签字或人工执行环节。AIT 设计时不能因为同一 L4 下其他任务是 Auto，就顺带把这些也做成全自动。

## 四、建议的承接节奏

配合 VNW 第一阶段的批量分析进度走，不是一次性铺开：
- **现在**：AIT 可以直接基于组 1 的 36 条任务开始设计，这是目前唯一真实、复核过的数据
- **第一阶段批跑推进时**：每有新 L3 从 MODEL_DRAFT 转为 REVIEWED，滚动并入 AIT 候选池
- **不建议**现在就基于组 2（未复核的 LLM 草稿）或组 3（数据不足/排队中）做工程决策——这两组的数字目前只是分析产物，不是复核结论
