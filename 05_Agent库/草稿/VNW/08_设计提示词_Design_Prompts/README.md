# 08 设计提示词

本层定义所有 L3 共用的分析模型，不为不同 L3 编写不同分析逻辑。

当前正式基线：

- 提示词：`L3统一分析模型_v1.0.md`
- 输入：系统生成的单 L3 事实证据包；
- 输出：`vnw.l3-analysis.v1` JSON；
- 状态：所有模型输出统一为 `MODEL_DRAFT`。

## 关键约束

- 只能引用当前事实包内的有效 `evidence_id`；
- 不访问事实包之外的知识；
- 不补造流程、任务、岗位、收益或象限坐标；
- 每个 L4 都要覆盖，复合动作原则上至少拆成两个可讨论任务；
- Skill 封装档位与 Human/Aug/Hybrid/Auto 是两条独立分析轴；
- 优先级必须分别说明数据依据、流程背景、风险限制和当前建议；
- 具体人名不进入系统展示，只保留岗位族、部门或授权角色；
- 临时、待复核和工作坊共识不能作为正式分析证据。

提示词变更必须同步更新版本、测试和已发布分析包的过期判断。
