# VNW v0.2.0 执行记录

## 本批范围

按 Agent 搭建 SOP v1.2 建立 01–11 骨架，并完成“检测→提取→状态提交”最小闭环。Phase1 提取器通过适配层复用，避免首批重写 700 余行已验证业务逻辑。

## 关键决策

- 用文件内容 SHA-256，替代旧原型的 mtime+size MD5 伪指纹。
- 只在提取成功且产物存在后提交状态，避免失败被误记为已处理。
- 所有产物与状态写 VNW 专属工作区，不写源项目。
- 常驻监听、规则合并、规则空白和 SOP 生成延后，遵循按风险递增迁移。

## 验证
