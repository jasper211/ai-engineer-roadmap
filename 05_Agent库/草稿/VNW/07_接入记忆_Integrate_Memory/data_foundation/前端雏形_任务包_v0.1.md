## 二、核心设计原则

1. **不要做15张表的15个页面**。要按"方法论推进阶段"组织信息，不是按数据表组织。
2. **方法论的视觉语言**：全局统一用三种颜色标识信号类型——
   - 🟢 A类·已确认规则（绿色）
   - 🔵 B类·访谈线索/待访谈（蓝色）
   - 🟡 C类·行动项/待裁定（黄色）
3. 雏形阶段：**纯静态展示+基本筛选/点击交互**，不需要编辑功能、不需要后端、不需要鉴权。

## 三、页面1：全域看板（首页）

**一句话定位**：让人一眼看到"72个节点，每个卡在哪个阶段"。

### 内容
1. **顶部统计条**（4个数字卡片）：
   - 总节点数：72
   - 已确认A类规则的节点数：根据T2去重node_id计数（目前应为8）
   - 仍只有B类线索待访谈的节点数：T1节点数 − A类节点数
   - 当前Gap总数：T7行数

2. **方法论推进漏斗**（横向堆叠条或漏斗图）：
   三段式：`信号已提取(72) → 已确认规则(8) → 完全闭环(0，暂时没有节点走完全流程)`
   用三色显示每段宽度比例

3. **按域分组的节点列表**（表格或卡片网格，按T1的domain字段分组）：
   每个节点显示：node_id / node_name / 一个"阶段徽章"（🟢已确认 / 🔵待访谈 / 🟡有Gap待裁定，取该节点在T2/T3/T7里出现的最高优先级状态）
   点击节点 → 跳转到页面2

### 判断节点阶段徽章的逻辑（伪代码）
```
if node_id 出现在 T2（有A类规则）:
    阶段 = "🟢 部分/全部规则已确认"
elif node_id 出现在 T7 且 priority含P0:
    阶段 = "🟡 有P0 Gap待裁定"
elif node_id 出现在 T3:
    阶段 = "🔵 仅有访谈线索，待访谈"
else:
    阶段 = "⚪ 未处理"
```

## 四、页面2：节点详情页（点击单个node_id进入）

**一句话定位**：单个节点的完整方法论推进轨迹，纵向铺开。

### 内容（按顺序纵向排列，不要用tab切换，要一页到底能看全）

1. **节点头部**：node_id + node_name + domain + 当前Gate评级（PASS/PARTIAL/FAIL，来自T1）+ 优先级

2. **交付物**（来自T6，按node_id筛选）：
   简单列表：交付物名称 + 形态(format) + 是否已外化(externalized)

3. **信号三分层**（核心区域，三个并排或纵向堆叠的色块区）：
   - 🟢 **A类·已确认规则**（来自T2，按node_id筛选）：每条规则展示 rule_name + 可展开看 rule_trigger/rule_action/rule_standard/rule_exception/rule_owner
   - 🔵 **B类·访谈线索**（来自T3，按node_id筛选）：每条展示 content + gap_description + target_interviewee（建议访谈人）+ status（待访谈/已访谈）
   - 🟡 **C类·行动项**（来自T4，按node_id筛选）：每条展示 action_description + action_owner + status

   如果某一类没有数据，该区域显示"暂无"，不要隐藏整个区块（要让人看到这个节点在三层里"缺"哪一层）

4. **Gap与裁定**（来自T7按node_id筛选 + T8按node_id筛选）：
   表格：description + priority + 如果在T8里有对应裁定项，显示question + status(待裁定/已裁定)

5. **复评状态**（仅当node_id出现在T13时显示）：
   review_result + blocker + last_update

## 五、页面3：访谈待办看板

**一句话定位**：回答"接下来该找谁访谈"。

### 内容
1. 从T3里筛选 `status == 待访谈` 的所有条目，按node_id分组
2. 每组显示：node_id / node_name / 待访谈条数 / target_interviewee建议人员（去重列出）
3. 按"待访谈条数"或按节点优先级排序，置顶建议优先处理的
4. 这个页面纯只读列表即可，不需要图表

## 六、技术要求（降低门槛，方便快速出雏形）

- 直接读CSV文件（前端fetch本地csv或用Python脚本先转成一份JSON再读JSON都可以，怎么快怎么来）
- 中文内容较多，注意CSV编码是 UTF-8 with BOM (utf-8-sig)，部分字段含有逗号/换行，要用规范的CSV parser（不要自己用split(',')硬解析）
- 不需要响应式移动端适配，桌面浏览器能看就行
- 配色：A类=绿色系，B类=蓝色系，C类=黄色/橙色系，Gap/P0=红色强调

---

## 七、明确不做的事（雏形阶段范围控制）

- 不做编辑/写入功能（只读展示）
- 不做T9/T11/T12/T14相关页面
- 不做登录鉴权
- 不做数据自动刷新/实时同步（手动放新CSV进去重新加载即可）
- 不需要做得视觉精美，能看清结构、能点击跳转即可
