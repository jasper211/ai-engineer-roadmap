# 07 接入记忆

本层保存 VNW 的可重建运行产物，不是新的业务 SSOT。

## 目录职责

- `model_snapshots/`：单 L3 事实快照、manifest 和全量索引；
- `analysis_runs/`：冻结后的模型运行包、输入 Hash 和执行记录；
- `analysis_packages/`：通过校验后发布的 `L3-CODE.model.json`；
- `reviewed_demos/`：历史人工复核 Demo 的兼容输入；
- `data_foundation/`：前端和模型共用的数据底座副本；
- `workspace/`：早期变更检测状态。

## 读取优先级

正式模型分析包优先于历史 reviewed Demo；不存在正式分析包时才允许使用兼容层，
且页面必须明确状态。不得用 reviewed 内容静默覆盖新快照。

## 生命周期

- 快照 Hash 变化后，旧分析运行包和工作坊草稿应显示过期；
- 发布前必须检查 L4 全覆盖、证据引用和任务归属；
- 修复或分批刷新已有分析包前创建时间戳备份；
- `.bak` 和历史运行目录用于审计，不应被前端当作当前版本；
- 所有产物都应能由源数据和脚本重建。

V1 不把浏览器本地工作坊结果写入本目录。
