# 04 定义 Agent

## Agent 定位

VNW Agent 是只读的 L3 流程模型编排器。它不负责创造业务事实，而是负责：

1. 读取并冻结单 L3 事实；
2. 判断 Gate M/E/A；
3. 构建统一模型运行包；
4. 调用或导入模型结果；
5. 校验证据、L4 覆盖、任务归属和快照时效；
6. 发布可被统一前端读取的分析包。

入口为 `agents/agent.py`，声明为 `agents/agent.yaml`。

## 当前能力

- 全量或指定 L3 快照构建；
- 蓝图结构解析；
- 统一分析包准备与执行；
- 已有分析包的任务/负责人决策修复；
- 单批最多 6 个 L4 的受控刷新；
- 分析结果导入、校验、备份和发布。

## 不承担的职责

- 修改 PostgreSQL；
- 自动修订 OB 或 EA 源文件；
- 将模型草稿升级为业务确认；
- 将浏览器工作坊结果写回权威层；
- 在 Gate M 未通过时强行调用模型。

## 固定运行链

`snapshot → gate → prepare → run/import → validate → publish → frontend`
