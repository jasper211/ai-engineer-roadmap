## 二、优化了什么（只改展示层 `DataLineage.tsx`，未改数据结构/类型）

### 1. 修正"未挂L4 ≠ 僵尸"的误导（核心）
- 原：单一红色 `zombie`（有数据但血缘/L4查不到 → 全标疑似僵尸）。
- 改：`relationStatus` 按原因分类：
  - `suspected` = 真断点（有数据但血缘、语义都查不到，非版本/配置表）→ 红
  - `version` = 历史/归档/快照（非僵尸，补版本指针）→ 天蓝虚线
  - `unmapped` = 配置/维度/规则（语义未排到，非僵尸）→ 深琥珀
  - `empty` = 0行未启用 → 浅灰

### 2. 生态位维度（角色分类落到视觉）
- 新增 `ROLE_TONE`：交付本体(紫) / 服务支撑(天蓝) / 独立工具配置(灰)。
- 已连入血缘的表按生态位着色；孤立类用关系警示色（见上），二者逻辑分离。

### 3. 证据角标（O/R/W/A/M）
- 对交付本体节点叠加角标：O=output产出 / R=rule规则已参数化 / W=workflow流程 / A=audit追溯 / M=映射。
- 对 AI 判断关键：一眼看出哪些环节逻辑已参数化（R）＝可接管信号。

### 4. 版本表标记
- 命名/类型含 history/snapshot/etl_scope/log 的表：虚线圆 + ⏱ 标记 + tooltip 提示"版本/归档"。

### 5. 图例升级
- 新增"生态位"、"证据角标"、"版本虚线"图例块，与"关系状态"分列。

### 6. 僵尸区块 → 分类呈现
- 从"一锅红"改为三分类：真断点(待人工)/版本归档(非僵尸)/配置维度(语义未排到)。

- 第一批 helper 中 `EVIDENCE_HINT`（证据角标说明映射）因早期一次编辑未真正写入代码，但渲染处（图例、选中面板）用它。
