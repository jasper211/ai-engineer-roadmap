# 统一L3分析执行器运行说明 v1.0

## 1. 固定流程

`prepare → run/import → validate → publish`

- `prepare`：冻结单L3事实包、快照Hash、提示词和输出契约；
- `run`：使用VNW自己的模型配置调用模型；
- `import`：允许导入外部模型JSON，但不绕过后续校验；
- `validate`：检查L4全覆盖、证据ID、任务归属和快照是否过期；
- `publish`：只发布通过校验的`L3-CODE.model.json`，已有包禁止静默覆盖。

## 2. 准备运行包

```bash
python3 05_Agent库/草稿/VNW/04_定义Agent_Define_Agent/agents/agent.py \
  --prepare-l3-analysis L3-IRR \
  --prepare-l3-analysis L3-KPI
```

## 3. 配置与运行模型

复制`02_配置项目_Configure_Project/deepseek_config.example.json`为
`deepseek_config.json`并填写VNW自己的Key，或者设置环境变量
`DEEPSEEK_API_KEY`。禁止读取其他Agent的密钥文件。

```bash
python3 05_Agent库/草稿/VNW/04_定义Agent_Define_Agent/agents/agent.py \
  --run-analysis-dir <analysis_runs下的运行包目录>
```

## 4. 导入外部结果

```bash
python3 05_Agent库/草稿/VNW/04_定义Agent_Define_Agent/agents/agent.py \
  --run-analysis-dir <运行包目录> \
  --import-analysis-output <模型输出JSON>
```

## 5. 安全边界

- 模型只能读取运行包中的事实；
- 所有模型结论必须引用当前事实包中的证据ID；
- 输入快照变化后旧结果禁止发布；
- 同一L3已有分析包时禁止静默覆盖；
- 模型输出一律标记`MODEL_DRAFT`；
- 发布分析包不等于负责人确认，也不修改数据库或知识库。
