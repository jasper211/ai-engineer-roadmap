## 1. 目的（为什么建这个延伸任务）

`PNL-001（P&L 定期核算）` 已经脱离 VNW 主流程，立项为一个**专属 P&L 项目**（P&L_EA 小组，桌面 `P&L_EA小组Jasper`）。

该 P&L 项目有一道硬性边界：**只能读，不能移动 / 修改 / 删减 / 增加任务文档**。因此在 P&L 项目里无法落地"围绕 P&L 的分析任务清单"。

VNW 侧仍要继续推进两件事，需要在**派生区**（而非 P&L 项目、也非 VNW 权威源头）挂一个任务承接面：

1. **VNW 前端搭建**：围绕 P&L 场景的业务数据分析前端入口（`scenario` / `business_scenario_analysis` 渲染）继续在 VNW 项目内建设。
2. **围绕 P&L 的分析任务**：佣金线与采购/人力的数据缺口补齐、口径核实、月结闭环等，作为本延伸任务跟踪。

本延伸任务只做**承接、跟踪、留痕**，不写回 VNW 权威源文件，也不改动 P&L 项目。

## 2. 边界（铁律，遵守「不造假不越界」）

| 区域 | 权限 | 说明 |
|---|---|---|
| **P&L 项目**（`P&L_EA小组Jasper`） | 🔒 只读 | 不移动 / 不修改 / 不删减 / 不增加任何任务文档；本延伸任务不产生任何写回 P&L 项目的文件 |
| **VNW 前端**（`VNW/10_部署与运行_Deploy_and_Run/frontend/`） | 可继续建设 | P&L 场景业务数据分析前端入口在此迭代（这是 VNW 内部建设，不属于"改动 P&L 项目"） |
| **VNW 权威源文件**（`07_接入记忆`、`08_设计提示词`等 01–12 工程层） | 只读 | 本延伸任务**不写回**这些权威源；只读取 |
| **本延伸任务文件夹**（`14_延伸任务_P&L分析/`） | 可写 | 承接、跟踪、留痕的派生产物全部落在这里 |

> 关键分辨：**在 VNW 前端里继续搭 P&L 场景的面是允许的**（属 VNW 后端建设）；**围绕 P&L 的分析执行任务（补数据源、配口径、建月结）**归本延伸任务跟踪，执行产出在此落盘，两边都不越界。

## 3. 本延伸任务当前结论基线（来自入口① PNL-001）

一句话：**今天不能端到端自动产出 P&L**。

| 组成项 | 类型 | 数据状态 | 支撑 |
|---|---|---|---|
| 收入（4类12条细分） | revenue | A · 有数据 | 佣金线（L3-COM），KPI_04 引用口径需重核（6 L3 仅 L3-COM 可靠） |
| 佣金拨出成本 | cost | A · 有数据 | 应收 / 实收 / 差异对照（L3-COM） |
| 采购成本 | cost | C · 无表 | 122 张表无采购成本来源；需确认外部核算方式或建 `fact_purchase_cost` |
| 运营 + 人力费用 | expense | C · 无表/建模缺口 | L3-HRA / L3-HRM Gate A 未过；需补薪酬表 `fact_employee_compensation` |

> 详细 L3 追溯、业务证据表行数、AI 增强（MODEL_DRAFT）见 `VNW/99_汇报产出/213_...md` 及 `PNL-001.json`。本延伸任务不做重复分析，只承接推进。
