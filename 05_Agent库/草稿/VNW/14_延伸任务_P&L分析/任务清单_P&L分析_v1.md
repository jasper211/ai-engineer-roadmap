## 3. 口径与合规纪律（沿用接手准则铁律）

- **不造假**：gap/state 一律来自 PNL-001 与实际查证，不编造行数、人名、系统、表结构。
- **不越界**：不移动/修改/删减/增加 P&L 项目任何文件；不改 VNW 权威源（01–13 的源文件），只读引用。
- **不略 Gap**：采购 / 人力的 C 状态缺口如实展示，标注「待补数据源 / 待确认」，不做推测填空。
- **待人工确认**：所有涉及财务口径（4类12条、KPI_04、核算系统）的结论，一律标注「待财务负责人确认」，不输出 CONFIRMED。
