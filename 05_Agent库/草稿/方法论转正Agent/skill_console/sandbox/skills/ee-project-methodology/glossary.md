# 术语表（按字母与拼音排序）

**Action** — 最小可管理任务，主账中必须有 ID、Owner、Due、状态、RAG、交付物、依赖、下一动作、证据和更新时间（Ch 6, Ch 7）
**Archive** — 被替代版本和历史依据的存放处，目录编号 90（Ch 5, Ch 10）
**BLOCKED** — 依赖或风险使下一动作无法继续，且已写明恢复方案；不得写成「等回复」（Ch 7）
**Case** — 一个真实业务对象的完整交付记录；线索、简历、需求方向、演示数据都不足以单独构成 Case（Ch 2）
**Case Manager 或 PM** — 维护共同事实、主账、RAID、Evidence、周报和升级；不编造业务或专业结论（Ch 4）
**Case Owner** — 推动单个真实对象达到成功、失败或终止结论（Ch 4）
**Change Log** — 事实与主账变更的追溯记录（Ch 2, Ch 5, Ch 7）
**CLOSED** — DONE 之后已回写主账、Case 和 Dashboard，残余风险有去向（Ch 7）
**CONDITIONAL GO** — 带附带条件和 Due 的 Gate 通过结论（Ch 8）
**CONFIRMED** — 已由有权 Owner 确认并进入当前基线的事实；七态中唯一可作为已完成事实的状态（Ch 5）
**Dashboard** — 从主账生成的管理视图，不是事实源（Ch 2, Ch 7）
**Decision** — 正式决策记录，事实优先级第 2 级（Ch 5）
**DELIVERED** — 交付物已提交但尚未验收；不得说成「已完成」（Ch 7）
**Disposition** — 恢复时对每项旧任务的处置结论（Ch 9）
**DONE** — 交付物存在、Evidence 已登记、验收人已接受（Ch 7）
**Evidence** — 支持状态和验收的记录，分 A/B/C/D 四级（Ch 7）
**FILE INDEX** — 入口文件中的当前文件清单，必须与当前主账和 Dashboard 一致（Ch 7, Ch 10）
**FUTURE SCOPE** — 当前周期之外的候选工作，不进入当前必达（Ch 5）
**Gate** — 阶段门，控制是否具备进入下一阶段的条件；G0 至 G5（手册写作 G零 至 G五）（Ch 8）
**ON HOLD** — 经 Decision 暂停，并有复审条件和日期（Ch 7）
**PLACEHOLDER** — 为建账预留的对象，不计入经营或交付成果（Ch 5）
**Principal（Project Principal）** — 整合交付、指定负责人、解决冲突、批准 Gate（Ch 4）
**PRINCIPLE AGREED** — 原则已同意，执行数字或文件未完成（Ch 5）
**PROPOSED** — 待批准建议（Ch 5）
**RAG** — 健康度（GREEN/AMBER/RED），与执行状态分开；GREEN 不等于完成（Ch 6, Ch 9）
**RAID** — 风险、问题、依赖、决策登记（Ch 7）
**Readback** — 责任签收：对角色、首个交付物、日期、执行人、依赖、替代方案作出回答；沉默不视为接受（Ch 6）
**SSOT** — 唯一事实源，指执行主账（Ch 7, Ch 10）
**SteerCo** — 战略、预算、重大风险和继续停止决策机构，双周审查（Ch 4, Ch 9）
**TARGET STATE** — 目标状态已确认，落地尚未完成；不得写成已完成（Ch 5, Ch 10）
**TASK TO VERIFY** — 需要指定责任人核验的事实（Ch 5）
**共同事实基线** — 已批准且有证据的事实集合，事实优先级第 1 级（Ch 5）
**六层项目控制模型** — 方向、事实、责任、执行、验收、汇报恢复六层（Ch 2）
**启动中 / 条件启动 / 阻塞** — 启动验收未通过时允许使用的三种项目状态表述（Ch 10）
**硬边界** — 上线、对外发布、使用真实个人数据、受规管活动、签约或收费；必须设专门 Gate（Ch 8）
**执行主账** — 结构化事实源，含 Action、Workstream、RAID、Decision、Case、Evidence Index（Ch 7）
