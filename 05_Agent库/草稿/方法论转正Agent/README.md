# 方法论转正Agent

## 现状（2026-07-25更新）

早期原型阶段，仅覆盖"行业自学习线 · 流程架构+AI协同两个方向"，**内部
治理线仍未启动**（按计划等 AIT 产出真实案例后再开始，见《三大主Agent
体系架构_v1.3》§6）。

**"无可执行代码"这个此前的表述需要澄清，不是"没有真实进展"**：行业自学习线
按设计就是对话驱动（Karpathy LLM-Wiki模式，人在Obsidian里用Claudian插件
对话摄入资料），不是Python批处理，所以确实没有.py代码，但已有**真实ingest
产出**——Obsidian vault的`方法论知识库/行业学习/`下`raw/`（原始资料，
支持PDF直接放入）+`wiki/`（sources/概念/实体/横向对比页）三层结构在
持续运转，已摄入多篇真实资料并产出结构化wiki页面，进度以vault内
`行业学习/wiki/index.md`为准（此文件更新频繁，不在本README重复写死数量）。

跨知识源融合（本Agent的卡片 ↔ OBagent的concept_atom原子）机制已设计但
**暂不启用**，等真实卡片积累更多后再对着真实数据验证，详见
`双Agent协作契约_OB与方法论转正Agent.md`。
