## 一、L3 端到端流程（非单线，两条独立触发的线）

**主构建线**（由VNW决策面板确认的任务触发）：

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐

│需求识别   │   │轨道判定   │   │AI化设计   │   │Agent构建  │   │SOP交付    │
│(读决策记录)│  │(三轨道+  │   │(含强制    │   │           │   │           │
│           │   │ Aug/Hybrid│   │介入点设计)│   │           │   │           │
│           │   │ 分流)     │   │           │   │           │   │           │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
```

**协同新规则观察线**（独立触发，不跟主线排队）：

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│试运行中冒出的 │ → │观察/验证暂存区│ → │稳定：转正回主线│
│不稳定规则     │   │(三路输入多方  │   │不稳定：流入   │
│              │   │ 评估+人工拍板)│   │方法论转正Agent│
└──────────────┘   └──────────────┘   └──────────────┘
```

这条线的前提是至少有一个主线构建的Agent真正上线运行、产生`fact_card`执行反馈——目前`fact_card`是0行，这条线现在没有真实输入，暂不能启动（见七节未决点）。

## 二、入口机制：决策确认记录（新增，衔接VNW机会台）

L3-AIT-01的输入不是"部门访谈记录"（旧`需求定义.md`的框架），而是VNW机会台"负责人决策·先试哪些AI任务"面板里被**明确选中**的任务。这个决策动作目前只存在于demo里手写的静态文字（比如COM demo的P0-1/P0-2...），没有留下机器可读记录，需要补一层结构化字段：

| 字段 | 说明 |
|------|------|
| `selected` | 是否被负责人选中进入试点 |
| `pilot_scope` | 最小试点范围（对应决策面板"最小试点"列） |
| `human_boundary` | 人工边界（对应决策面板"人工边界"列） |
| `selected_by` / `selected_at` | 谁在什么时候确认的，留痕 |

这层字段该加在`model_snapshots`的`analysis.priority_drafts`旁边，还是单独一张表，待定（见七节）。**核心原则**：能进L3-AIT-01的任务，必须是这层"决策确认"标记过的，不是`analysis.tasks`里所有LLM草稿任务，也不是所有Auto-tier任务的自动批量灌入。

## 三、轨道判定逻辑（L3-AIT-02，2026-07-30确认）

判定优先级从高到低：

1. **资金安全强制关卡 / 物理执行类**（`skill_feasibility.funds_safety_hard_gate` 或 `physical_execution` 为真）→ 无论建议Tier是什么，直接判入**人的规则轨道**，不构建Agent/Skill，只出介入点设计文档。这是风险覆盖原则，优先级最高，不可被Tier覆盖。
2. 排除第1条后，按`suggested_tier`分：
   - **Auto** → 机器规则轨道，走标准五步走，产出纯Agent/Skill
   - **Aug / Hybrid** → 机器规则轨道，同样走标准五步走，但AI化设计步骤（L3-AIT-03）**强制**多产出一份介入点设计（复用人的规则轨道的方法论），区分两种关卡形态：
     - Aug：固定关卡——AI产出后，人**必须**逐次确认才能放行
     - Hybrid：条件关卡——AI走标准路径，只有命中明确异常判定条件才转人工，正常case不经过人
   - **Human** → 人的规则轨道，只出介入点设计文档
3. 协同新规则（试运行中冒出的、不在VNW分析产出里的新规则）→ 不进入1/2的判定，直接进观察区（见一节协同新规则观察线），暂无真实输入无法启动

## 四、每个L3-AIT步骤的输入输出

| L3 编码 | 名称 | 输入 | 输出 | 对应 skill/tool |
|---------|------|------|------|---------|
| L3-AIT-01 | 需求识别 | 决策确认记录（二节字段） | 待处理任务清单（含pilot_scope/human_boundary） | （待设计）决策确认读取器 |
| L3-AIT-02 | 轨道判定 | 待处理任务 + `skill_feasibility` + `suggested_tier` | 轨道标签（机器/人的/观察区）+ 关卡类型（固定/条件，仅Aug/Hybrid） | （待设计）轨道判定器 |
| L3-AIT-03 | AI化设计 | 轨道标签 + L4蓝图/规则/SOP材料 | Agent/Skill设计文档；Aug/Hybrid另加介入点设计文档 | （待设计）介入点设计生成器 |
