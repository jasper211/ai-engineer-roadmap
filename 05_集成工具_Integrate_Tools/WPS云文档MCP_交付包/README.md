# WPS 云文档 MCP Server · 交付包

**版本 0.2.0** · 2026-09-16

让 AI Agent（Claude Code 等）直接读取企业 WPS 团队云文档：列库 → 浏览目录 → 读表格/读文档正文。

> **变更记录**
> - **0.2.0** — 新增 `wps_read_document`：可读 Word(.docx)/PPT(.pptx)/纯文本**正文**（共 11 个工具）。
>   补充简繁混用的规避提示（搜索与正文关键词都需简繁各试一次）。
> - **0.1.0** — 首版，10 个工具：授权、列库、浏览目录、浅层搜索、读表格。

**无需安装任何第三方依赖**，有 `python3`（3.9+）就能跑。

---

## 快速开始（约 5 分钟）

### 前置：找管理员要两个值

**APPID** 和 **APPKEY** —— 这是企业自建应用的凭证，不是你的个人账号密码。
管理员如果还没建应用，让他看 [docs/管理员_后台配置说明.md](docs/管理员_后台配置说明.md)。

### 第 1 步：填配置

```bash
cp wps_config.example.json wps_config.json
```

用编辑器打开 `wps_config.json`，把 `app_id`、`app_key` 换成管理员给的值。

> ⚠️ 注意引号必须是半角 `"`。从聊天软件复制过来经常会变成中文引号 `“ ”`，那样 JSON 会解析失败。

### 第 2 步：授权

```bash
python3 wps_sync.py auth
```

会自动打开浏览器让你授权。授权后 token 存在 `~/.wps_mcp/`，**有效期 365 天**。

**这一步不能省**：团队文档库必须用用户身份访问，应用身份会直接报
`400002059 用户不在企业内`。

授权拿到的权限**跟随你本人**——你在 WPS 里能看到哪些库，Agent 就能读哪些，读不到别人的。

### 第 3 步：自检 + 接入

```bash
python3 verify.py
```

逐项检查环境、凭证、授权、server 启动。**全部通过后，它会直接打印出该粘贴到
`~/.claude.json` 的配置片段**，照着贴进 `mcpServers`，重启 Claude Code 即可。

哪一项没过，按它给的 `→` 提示处理，然后重跑。

## 能做什么

| 工具 | 用途 |
|---|---|
| `wps_list_libraries` | 列出你能访问的全部团队文档库 —— **从这里开始** |
| `wps_list_folder` | 列出某目录下一层的文件夹和文件 |
| `wps_search_files` | 在一个库里浅层搜索表格 |
| `wps_read_sheet` | 读 .xlsx / .et / .ksheet，输出表格网格 |
| `wps_read_dbsheet` | 读多维表格 .dbt |
| `wps_read_document` | 读 Word/PPT/纯文本正文（不支持 PDF、旧版 .doc） |
| `wps_file_info` | 文件元信息 |
| `wps_resolve_link` | 分享链接 → file_id |
| `wps_auth_status` / `wps_auth_start` / `wps_auth_complete` | 授权管理 |

装好后直接对 Agent 说「列一下我能访问的 WPS 文档库」就行。

## 必须知道的三个限制

1. **不提供全库遍历。** 遍历成本在目录数量（每个目录一次网络往返）。实测一个有 355 个目录、
   5782 个条目的库，并发 6 路仍需 157 秒。所以 `wps_search_files` 是受限浅层搜索，
   **结果不全时会明确提示**，不会静默返回残缺数据。

2. **PDF 和旧版 .doc 读不到正文。** Word(.docx)、PPT(.pptx)、纯文本都能读正文；
   PDF 和二进制 .doc 需要专门解析库，不在零依赖范围内。合同类文件常有 .docx 和 .pdf
   两个版本，优先读 .docx。

3. **中文简繁混用。** 搜索和正文关键词都是精确匹配、不做简繁转换。实测同一文件夹里
   文件名简繁混用，甚至文件名是简体、正文是繁体。**中文关键词请简繁各试一次。**

4. **表格按选区读。** 默认前 200 行 × 30 列，大表要分块读。超出范围不会提示缺失。

## 安全须知

- `wps_config.json` 里有 **APPKEY**，等同于应用密钥。**不要提交到代码仓库、不要转发给外部**。
- `~/.wps_mcp/user_token.json` 是你的个人授权凭证，权限 0600，不要拷给别人——
  别人拿到就等于用你的身份读数据。
- 你读到的可能包含**真实业务数据和个人信息**（姓名、证件号、保单号等）。
  Agent 能读到的范围 = 你在 WPS 里能看到的范围，请按公司数据合规要求使用。

| 文件 | 说明 |
|---|---|

| `wps_client.py` | WPS 开放平台只读客户端（只实现读接口，无任何写操作） |

| `docs/MCP接入指南.md` | 详细接入文档 |
| `docs/管理员_后台配置说明.md` | 给管理员：建应用、申请权限、配回调（含实测校准的权限清单） |

## 排查

```bash
python3 verify.py              # 先跑这个，多数问题它会直接告诉你原因
python3 wps_sync.py doctor     # 看当前用的是用户身份还是应用身份
python3 wps_sync.py ls         # 列团队库，验证权限是否生效
```

遇到权限类报错，**看平台返回的原文**——它会直接点名缺哪个 scope，把那句话发给管理员即可。
