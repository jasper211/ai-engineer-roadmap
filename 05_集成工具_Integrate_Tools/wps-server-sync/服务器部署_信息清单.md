# WPS 云文档同步 · 服务器信息清单

用途：在服务器上部署一个定时任务，每天把 WPS 企业云文档同步成本地完整副本
（新增/修改/删除都同步）。以下信息用于确认服务器是否满足条件、以及怎么部署。

> **不需要提供**：服务器密码、SSH 私钥、公网 IP。
> 程序直接跑在服务器本机，不需要从外部连入，也不需要我们远程登录。

## 二、需要确认的问题（请运维答复）

| # | 问题 | 为什么需要 |
|---|---|---|
| 1 | 可用磁盘空间有多少？挂载在哪个目录？ | 云盘约 30GB，建议预留 50GB 以上 |
| 2 | 能否安装软件？（一个约 10MB 的二进制 + 无 pip 依赖的 python 脚本） | 需要装 `wps365-cli`（金山官方 CLI） |
| 3 | 出网是否受限？能否访问 `openapi.wps.cn`（443）？ | 全部数据经此接口获取，走不通则方案不成立 |
| 4 | 是否有出网代理？如有，代理地址是什么？ | 需要给程序配 `HTTPS_PROXY` |
| 5 | 用哪个系统账号运行？是否需要 sudo？ | 程序不需要 root，普通账号即可 |
| 6 | 文件系统字符集是否 UTF-8？ | **文档名大量为中文**，非 UTF-8 会乱码甚至写入失败 |
| 7 | 谁能访问同步目录？有无访问审计？ | 见下方安全说明，这条必须有明确答复 |
| 8 | 定时任务用 cron 还是 systemd timer？ | 部署方式不同 |
| 9 | 是否有磁盘监控/告警？ | 云盘持续增长，写满会导致同步失败 |
| 10 | 服务器时区？ | 定时任务时间点以此为准 |

## 三、最低配置要求

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Linux（推荐）或 macOS | Windows Server 需另行适配 |
| python3 | **3.9 及以上** | 不需要 pip 安装任何包 |
| curl | 任意版本 | 下载文件用 |
| 磁盘 | **50GB 以上可用** | 云盘约 30GB，留余量 |
| 内存 | 1GB 以上 | 程序本身占用很小 |
| 网络 | 能访问 `openapi.wps.cn:443` | 下载速度实测约 400KB/s |
| 字符集 | **UTF-8** | 中文文件名 |

## 四、部署方式说明（供运维预估工作量）

1. 安装官方 CLI：`curl -fsSL https://open-docs.wpscdn.cn/cli/install.sh | bash`
   （装到用户目录，**不需要 root**）
2. 放置同步脚本（单个 python 文件）
3. 执行一次授权 —— **需要人工介入一次**：
   命令行会输出一个链接和验证码，**在任意一台有浏览器的电脑上**打开并确认即可，
   服务器本身不需要图形界面。授权有效期 **365 天**，之后自动续期。
4. 配置定时任务（建议每天凌晨执行一次）
5. 首轮为全量下载，耗时较长（视网络与数据量，可能数小时），
   之后每轮只下载变化的文件。中断可续，不会重复下载。

## 五、安全事项（需业务方确认，非技术问题）

同步完成后，服务器上会存有企业云文档的**完整副本**，其中包含：
保单号、客户姓名、身份证号、银行账号等敏感信息。

**文件一旦落到服务器，WPS 原有的权限控制即不再生效** —— 此后能访问该目录的人，
即可看到全部内容。因此需要明确：

- [ ] 同步目录的访问权限如何设置？限定哪些账号？
- [ ] 服务器是否有访问审计？
- [ ] 是否需要磁盘加密？
- [ ] 数据保留策略？是否需要备份？备份介质的权限如何控制？
- [ ] 该服务器是否可从公网访问？如是，是否有额外防护？

以上属于数据治理范畴，需要业务负责人确认后再行部署。
