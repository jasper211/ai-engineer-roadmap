# 证据等级、语言权限与命题升级协议 v0.1

## 1. A/B/C 属于命题，不属于来源

官方来源只能直接支持它实际披露的内容；专家观点证明“专家如何判断”，不自动证明市场机制；同一页可以同时存在A、B、C命题。

## 2. A级：直接支持

最低条件：描述、比较或合法分解命题；存在direct Fact；时间、对象、口径、分母一致；派生结果可复算；没有影响方向的关键冲突；通过Data Steward复核。

允许语言：“数据显示”“由X变为Y”“占总增量Z%”“在该口径下排名”。

## 3. B级：支持机制但存在替代解释

最低条件：至少一条near evidence；原则上至少两条独立证据链；有替代解释、反证和升级条件；通过Industry Challenger复核。

允许语言：“与……机制一致”“支持……可能性”“可能通过……发生”“仍需……验证”。不得使用“证明了”“导致”“客户因此选择”。

## 4. C级：重要但证据不足

适用于客户动机、经营动作、利润价值缺少直接数据，或只有观点/个案/相关性，或关键冲突未解决，或请求颗粒度高于事实底座。

只允许写成待验证命题、资料缺口或研究问题，不得进入确定性标题和行动依据。

## 5. 独立证据链

独立性按原始生成过程判断：IA数字被多篇媒体转载仍是一条链；IA事实加公司披露可能是两条链；两位专家引用同一报告仍共享一条事实链。Evidence Link 必须记录 `origin_chain_id`。

## 6. 命题状态机

```text
candidate → drafted → evidence_attached → challenged
→ supported_A / supported_B / blocked_C
→ published → superseded / retired
```

Agent不能因文字合理而自动升级。

## 7. 冲突协议

| 冲突 | 处理 |
|---|---|
| definition_conflict | 回到指标合同 |
| period_conflict | 回到Baseline |
| scope_conflict | 拆分对象集 |
| source_conflict | 查原始来源和版本 |
| mechanism_conflict | 保留替代解释 |
| experience_conflict | 限定情境并补证据 |

关键冲突未解决时，Claim保持`challenged`或`blocked_C`。

## 8. 反证设计

每个机制命题必须回答：如果为真还应观察到什么；什么事实会削弱或推翻它；哪些替代解释会产生相同表象；下一项最有区分力的证据是什么。

## 9. 页面权限

| 页面位置 | A | B | C |
|---|---|---|---|
| 主标题 | 可以 | 人工批准且保留概率语言 | 禁止 |
| 图表Insight | 可以 | 标记机制/待验证 | 只作问题提示 |
| 综合判断 | 可以 | 附替代解释 | 不作为结论 |
| 行动建议 | 结合目标与约束 | 只建议验证/试验 | 只列数据升级 |
| 附录 | 可以 | 可以 | 可以 |

Recommendation 还必须包含决策目标、可控变量、成本约束、风险、监测指标和责任人。

## 10. Reviewer检查候选

- Claim至少有一条Evidence Link；
- A级全部链接direct Fact；
- B级有替代解释和反证；
- C级未进入标题；
- Evidence按origin chain去重；
- Fact期间、对象、单位与Claim scope一致；
- 派生Fact有公式和输入Fact；
- 页面可回到Claim与Fact。
