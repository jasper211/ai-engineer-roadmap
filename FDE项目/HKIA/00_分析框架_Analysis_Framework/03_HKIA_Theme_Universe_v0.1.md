# HKIA Theme Universe v0.1

> 状态：Phase A 初版。用途是问题路由与来源规划，不是报告目录；主题边界会通过真实分析案例持续校准。

## 1. 划分原则

Theme 与 Dimension 不相同：

- **Theme** 是一组稳定的决策问题，例如“渠道竞争力如何迁移”。
- **Dimension** 是解释坐标，例如代理/银保/经纪。
- **Metric** 是证据，例如 NOP、APE、份额和件均。
- **Report** 是针对特定读者对一个或多个 Theme 的一次组织。

主题划分遵循五条规则：

1. 一个主题必须对应可复述的决策问题，而不是数据表名称。
2. 一个主题只有一个主解释轴，可以有平行验证轴。
3. 主题之间允许传导，但贡献率不能跨互斥维度相加。
4. 数据不可得不等于主题不存在；应明确“当前不可回答”。
5. 每个主题必须声明禁止推断和证据升级路径。

## 2. 主题全景

### A. 市场结果层：市场发生了什么

| ID | 主题 | 核心决策问题 | 主解释轴 |
|---|---|---|---|
| T00 | 市场规模与周期 | 市场处于扩张、恢复还是结构性换挡 | 时间 |
| T01 | 增长质量与价值转换 | 增长是现金规模、持续化价值还是利润增长 | 口径/缴费 |
| T02 | 业务状态与保有质量 | 新造增长能否转化为有效业务并留存 | 业务状态 |

### B. 结构机制层：增长由什么构成

| ID | 主题 | 核心决策问题 | 主解释轴 |
|---|---|---|---|
| T10 | 产品结构与需求承接 | 哪类产品承接增长，产品组合如何迁移 | 产品 |
| T11 | 缴费方式与量价结构 | 趸交/期交、保单数和件均如何驱动增长 | 缴费年期 |
| T12 | 渠道竞争与分销迁移 | 增量由哪些渠道承接，渠道位置如何变化 | 渠道 |
| T13 | 币种与资金配置 | 资金偏向什么币种，配置结构如何变化 | 货币 |
| T14 | 客群与跨境需求 | 本地/内地访客等客群如何影响市场 | 客群/地域 |

### C. 竞争捕获层：谁获得了结果

| ID | 主题 | 核心决策问题 | 主解释轴 |

| ID | 主题 | 核心决策问题 | 主解释轴 |
|---|---|---|---|
| T30 | 监管与资本制度 | 监管变化如何改变产品、渠道和公司行为 | 事件/制度 |

| T32 | 行业价值链与盈利 | 增长如何传导至利润、资本和长期价值 | 价值链 |

## 3. 主题传导关系

```text
T30 监管/资本 ─┐
T31 宏观/金融 ─┼→ T10产品 / T11缴费 / T13币种 / T14客群
               │                     ↓
               └──────────────→ T12渠道迁移
                                      ↓
T22中介产能 ───────────────────→ T20公司捕获
                                      ↓
T00市场规模 → T01增长质量 ─────→ T21公司能力
                                      ↓
                               T02保有质量 → T32盈利价值
```

这只是分析导航，不代表已证明的因果关系。每条箭头必须在具体任务中转换为命题并绑定证据。

## 4. 逐主题路由与证据要求

| ID | 必需证据 | 优先来源 | 当前 HKIA 覆盖 | 主要禁止推断 |
|---|---|---|---|---|
| T00 | 年度/季度总量、路径、断点 | IA、监管新闻稿 | 强 | Q1不得替代全年；断点不得解释为经营变化 |
| T01 | NOP/APE、整付/年度化、利润/资本 | IA、公司披露 | 中 | APE不得等同利润或EV |
| T02 | 新造、有效、终止、持续率 | IA、公司披露 | 弱-中 | 有效业务余额不得直接等同留存质量 |
| T10 | 产品金额、份额、件数、合法交叉 | IA、产品资料、公司披露 | 中，跨RBC分类断点 | 新旧产品分类不得强行映射 |
| T11 | 整付/期交、年期、保单数、件均 | IA | 强 | 件均不得解释为客户财富或利润 |
| T12 | 渠道金额、份额、增量、公司落点 | IA、公司披露、行业媒体 | 强 | 渠道事实不得直接证明客户偏好 |
| T13 | 币种金额、份额、产品交叉 | IA、宏观数据、公司资料 | 强-中 | 币种选择不得直接等同投资目的 |
| T14 | MCV/地域、客群、跨境事件 | 独立MCV数据、调研、媒体 | 缺失 | 长期业务季度表不能推断MCV占比 |
| T20 | 公司金额、份额、排名、CR/HHI | IA、公司披露 | 强 | 排名不得直接等同综合竞争力 |
| T21 | Peer、结构、趋势、比率、经营动作 | IA、年报、访谈、老板经验 | 中 | 监管事实不能证明具体经营动作 |
| T22 | 代理人数、活跃率、产能、留存 | 中介统计、公司数据、调研 | 缺失 | 渠道份额下降不能直接归因代理产能 |
| T30 | 规则文本、时间点、实施范围、前后变化 | IA/HKMA/政府、法律解读 | 弱 | 同期发生不等于监管导致 |
| T31 | 利率、汇率、市场、跨境流量 | HKMA、政府、市场数据 | 缺失 | 宏观相关性不等于客户动机 |
| T32 | 利润、EV、资本、持续率、成本 | 公司披露、内部数据 | 缺失 | NOP/APE增长不得直接翻译成盈利增长 |

## 5. 来源进入主题的路由示例

| 输入 | 首要路由 | 次要路由 | 处理方式 |
|---|---|---|---|
| IA 长期业务 Excel | T00/T01 | T10-T13、T20 | 解析为 Fact，保留表式版本 |
| IA 监管通告 | T30 | 受影响主题 | 建 Event 与 Policy Evidence |
| 公司年报渠道表述 | T21 | T12/T32 | 建 Company Claim，不直接覆盖监管事实 |
| 公众号渠道趋势文章 | T12 | T14/T21 | 拆出引用事实、作者观点和机制假说 |

| 老板经验判断 | 对应主题 | T21/T32 | 建 Experience Card，记录情境、案例和反例 |

## 6. 当前优先级

### 第一批：用于打通完整流程

1. **T12 渠道竞争与分销迁移**：现有事实强，且需要外部文本补机制，适合验证多源融合。
2. **T01 增长质量与价值转换**：训练 NOP/APE、价值边界和证据升级。
3. **T20 公司格局与市场集中度**：现有公司事实较强，适合测试实体、Peer和具名归因。

### 第二批：扩大机制解释

- T10 产品、T11 缴费、T13 币种、T30 监管。

### 第三批：需要新增关键数据源

- T14 客群/跨境、T22 中介产能、T31 宏观、T32 盈利价值、T02 保有质量。
