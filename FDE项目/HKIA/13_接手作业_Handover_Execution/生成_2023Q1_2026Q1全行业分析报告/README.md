## 报告结构（39 屏）
一、方法框架（六层协议/十维度/七步/反模式/三镜/证据分级）
二、数据与口径合同（时间 Baseline/断点双链/多口径/来源认证）
三、全行业总览（规模/结构/同季同比）
四、三大业务类深入：个人（总量/双口径 NOP-APE/量价/趋势）、团体（新造/有效/注解）、退休（数量/基金/供款）
五、公司层：谁捕获（整付/年度化/保单排名、增量贡献、转移事件、异常复核）
六、综合结论（谁增长/三镜根因/DoD 自查/结论与边界）
七、附录（公式/证据索引/来源/免责）

## 数据与口径纪律（关键）
- 数据来源：HKIA 长期业务临时统计，经接手前标准化为认证资产；全屏 `provisional` 标签。
- 增长一律**同季同比**（2023Q1→24→25→26Q1），不跨期年化。
- 个人业务 NOP/APE 双口径并列，不二选一。
- 团体/退休按各自原生口径读，不与个人保费混算。
- 缺失值保持空、绝不补零；异常（Chubb/BOC 极端同比、团体受保人峰值）按 C 级复核标注。
- 公司转移事件（Canada Life→MyPace）经 lineage 桥接，不作有机增长误读。

## 边界（遵用户确认）
仅**个人业务 / 团体业务 / 退休计划**三大类；不做产品细分、渠道、货币、缴费年期、MCV、在岸/离岸交叉。机制性结论（渠道/客户动机/利润）为 C/D，等待外部证据。
