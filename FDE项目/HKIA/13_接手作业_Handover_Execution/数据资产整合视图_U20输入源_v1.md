# HKIA 数据资产整合视图 · 供 U20 作为输入源

> **用途**：把 HKIA 现有各数据库资产整合成一份 U20 可直接对接的"输入源总览 + 表结构 + 口径约定"。
> **依据**：接手作业各 `生成_` 目录 + 主库 `hkia.db`（实测读表核对）。
> **日期**：2026-08-06。列为活文档，资产更新后同步。

---

## 一、一句话总览

HKIA 已形成 **5 个数据库资产**，覆盖：
- **季度**：2015Q1–2026Q1（主库）+ 2023Q1–2026Q1（标准事实层）
- **年度 certified**：2022/2023/2024（年度公司层）
- **年度 provisional**：2025（provisional 公司层 + 标准层 annual_facts）
- **行业财务**：2024Q4–2026Q1 共 6 期（2025Q2 已用官网 PDF 补齐）

所有核心层均经过 **reconcile QA 验证**（市场总额=公司加总等）。

## 三、口径与单位约定（U20 对接必需）

| 约定 | 说明 |
|---|---|
| **金额单位** | 行业财务层 = HKD_million；其余公司/市场层 = HKD_thousand（`$'000`）⚠️ 不混加 |
| **保单/受保人/计划数** | count；`保单数`/`受保人数`/`计划数(scheme)` 不可跨指标相加 |
| **certified vs provisional** | 2022/2023/2024 = certified；2025 = provisional；2026Q1 起季度 = provisional。各层认证字段：财务层= `certification` 列；2025层= `certification` 列；年度层= 由 `report_year` 推断；标准月度层= provisional |
| **schema 切换** | 2024Q3 起 RBC（分类分红/其他/相连）；pre-RBC（A-F 类别）。跨 schema 同环比需 bridge |
| **公司改名/转让** | 安盛/萬通/周大福/安達、Canada→MyPace 等在 identity/lineage 桥承接；引用公司趋势勿把转让当自然增长 |
| **L11 退休计划** | 2022/2023=L11 保單数+lives；2024=L11 scheme_count。L13 并入方式按 schema 路由 |
