## 二、最常用的 4 类查询（已实测可用）

### Q1 · 市场整体趋势（标准事实层 market_facts）
```sql
SELECT period, metric_id, value, unit
FROM market_facts
WHERE metric_id='NB_IND_TOTAL_ANNUALIZED_PREMIUM'   -- 个人新造年度化保费
ORDER BY period;
```
其他常用 metric_id：
- NB_IND_TOTAL_SINGLE_PREMIUM / NB_IND_TOTAL_ANNUALIZED_PREMIUM（个人新造整付/年化）
- NB_GROUP_* （团体新造）
- IF_IND_TOTAL_POLICIES / IF_IND_TOTAL_SUMS_ASSURED_OR_ANNUITIES（个人有效）
- IF_RETIREMENT_*（退休计划）
完整 18 指标见 `schema_metrics` 表。

### Q2 · 年度公司排名（年度公司层 company_facts）
```sql
SELECT insurer_name_source, value_raw
FROM company_facts
WHERE report_year=2024 AND table_id='L16'      -- L16=个人新造总额
  AND metric_sem='premium_single'
  AND entity_scope='insurer'
ORDER BY value_raw DESC LIMIT 10;
```
- L8-L13 = 有效业务；L14-L19 = 新造业务
- metric_sem：premium_single/premium_annual/policy_count/current_estimate/net_liabilities 等

### Q3 · 2025 公司级（2025provisional 公司层）
```sql
SELECT insurer_name_en, value
FROM provisional_company_facts
WHERE metric_sem='nb_total_single_premium' AND entity_scope='insurer'
ORDER BY value DESC LIMIT 10;
```

### Q4 · 行业财务/资产配置（财务层 financial_facts）
```sql
SELECT item_label_zh, value_hkd_million
FROM financial_facts
WHERE period='2026Q1' AND fund_scope='long_term'
  AND item_id IN ('debt_securities','equities_portfolio','cash_and_deposits')
ORDER BY value_hkd_million DESC;
```
- fund_scope：industry_total / long_term / participating_long_term / general_business

## 三、口径约定（务必遵守，避免 U20 误用）

| 约定 | 说明 |
|---|---|
| **金额单位** | 财务层=`HKD_million`；其余层=`HKD_thousand`(千港元) ⚠️ 不混加 |
| **count vs 金额** | 保单数/受保人数/计划数=count，与金额字段不混加 |
| **certified vs provisional** | 2022/2023/2024=certified；2025=provisional；2026Q1季度=provisional。引用带标签 |
| **schema 切换** | 2024Q3 起 RBC（分红/其他/相连）；pre-RBC（A-F类别）。跨 schema 同环比需 bridge |
| **公司改名/转让** | 安盛/萬通/周大福/安達、Canada→MyPace 在 identity/lineage 桥承接；勿把转让当自然增长 |
| **L11 退休计划** | 2022/23=L11 保单数+lives；2024=L11 scheme_count |
| **year(季度) axis** | 标准事实层用 `period`(如 2023Q1)；年度层用 `report_year` |

## 四、U20 调用建议

### 4.1 推荐入口
- **首选**：标准事实层（Q1）+ 年度公司层（Q2）+ 财务层（Q4）三库组合，覆盖市场/公司/财务三维。
- 需 2025 当年公司口径时，加 2025provisional 公司层（Q3）。

### 4.2 若需"公司维度 + 年度连续性"
```sql
-- certified(2024) vs provisional(2025) 对比同公司新造保费
-- 注意 scope 差异：2024 L16 个人寿险 vs 2025 L1 个人长期(含年金)
SELECT '2024' AS yr, insurer_name_source, value_raw AS new_biz_premium
FROM annual_company_fact_layer_2022_2024.db.company_facts
WHERE report_year=2024 AND table_id='L16' AND metric_sem='premium_single';
-- 交叉工程方法见各目录 scripts/query_examples.py
```

### 4.3 性能/稳定性
- 各 DB 为只读 SQLite，可直接连接；查询秒级返回。
- 建议用只读连接（`sqlite3.connect('file:...?mode=ro', uri=True)`）防止误写。
