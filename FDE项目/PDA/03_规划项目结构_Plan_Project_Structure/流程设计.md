## 一、能力线说明

demo 只有一条线性流程：**底表读取 → 清洗标准化 → 多维聚合 → 看板生成**。跑一次生成一份 HTML 即可，暂不做调度/增量（阶段二前提未确认，见需求定义 4.2）。

## 二、L3 端到端流程

```
┌───────────┐    ┌───────────┐    ┌───────────┐    ┌───────────┐    ┌───────────┐
│ L3-PDA-01 │ →  │ L3-PDA-02 │ →  │ L3-PDA-03 │ →  │ L3-PDA-04 │    │ L3-PDA-05 │
│ 底表读取   │    │ 清洗标准化 │    │ 多维聚合   │    │ 看板生成   │    │ 报表衍生字段│
│ +完整性校验│    │ (含真问题修复)│  │ (7类矩阵) │    │ (HTML)    │    │(S8的13个字段)│
└───────────┘    └───────────┘    └───────────┘    └───────────┘    └───────────┘
```

L3-PDA-05 是独立分支，接在 L3-PDA-02 之后、不依赖 L3-03/04——它服务的是"复刻9-sheet专题报表"这条后续能力线，跟"生成看板"这条能力线目前是并行、不交叉的两条线（呼应 SOP 第2步"不是所有Agent都只有一条线性流程"的提醒）。

## 四、L3-PDA-02 清洗规则明细（直接对应需求定义第七、十一节，逐条可测试）

| 规则 | 依据 |
|------|------|
| 剔除 `policy_id=='订单编号'` 的表头残留行 | 需求定义 7 |
| `res_date`/`sign_date`/`submit_date`/`issue_date`：单元格为 `int`/`float` 时按 Excel 序列号（`datetime(1899,12,30)+timedelta(days=值)`）换算；为 `datetime`/`date` 时直接用 | 需求定义 11.2【真问题1】 |
| `future_dated` = `sign_date` 晚于底表文件名日期（从文件名正则提取 `YYYYMMDD`，取不到则退化用文件 mtime） | 需求定义 11.3【真问题2】——不再硬编码 2026-07-24，換成从文件名动态解析，避免底表更新后阈值过期 |
| `policy_status_tier` 映射：`生效`→生效；`待批核/pending/排期/已签单/尚欠保费`→在途；`取消投保/退保/搁置受保/拒保`→终止（沿用阶段一原型footer已经写死的口径，不是本次新发明） | 需求定义 七 |
| `premium`/`ape` 缺失按 0 处理 | 需求定义 七 |
| `sum_assured` 的全角/半角空格值统一转 `NaN`（不当有效值参与后续任何聚合） | 需求定义 11.4 |
| `currency_code` 缺失归为 `"未填"` | 需求定义 七 |
| `sum_assured`/`SQ_rate`/`referral_code`/`premium_term` 本版本**不参与任何聚合**，清洗时保留原样透传，不清洗不假装处理——docstring 里显式注明"已知未处理" | 需求定义 11.4 |

## 五、L3-PDA-03 多维聚合口径（对齐阶段一原型 `DATA` 结构，需求定义第八节 7 类矩阵）

聚合全部以**清洗后的 `premium`（已折算港币）** 为金额口径，`count` 为记录数：

| 聚合键 | 维度 | 对应第八节矩阵项 |
|---|---|---|
| `by_entity_all` | issuing_entity | 1 业绩趋势的基数 |
| `by_entity_month` | issuing_entity × 签单月份(`sign_date` 取 `YYYY-MM`) | 1 业绩趋势 |
| `by_entity_bcat` / `by_entity_mkt` | issuing_entity × business_category / market_segment | 2 业务结构 |
| `by_entity_prod` / `by_entity_carrier` | issuing_entity × product_category / carrier_code（carrier 按保费 top6 + 其他分桶，沿用阶段一原型口径） | 3 产品与保司结构 |
| `by_entity_cust` | issuing_entity × customer_type | 4 客户结构 |
| `by_entity_status` | issuing_entity × `policy_status_tier` | 5 状态结构 |
| `cycle_avg` | issuing_entity → 平均(`issue_date - sign_date`天数)，仅统计两个日期都非空的记录 | 6 运营效率（用修正后的日期计算，消除【真问题1】的污染） |
| `fin_by_entity` | issuing_entity → [`Is_Premium_Financing==1`计数, 总数] | 7 风险结构·融资单占比 |
| `by_entity_ccy` | issuing_entity × currency_code | 7 风险结构·非本币占比 |
