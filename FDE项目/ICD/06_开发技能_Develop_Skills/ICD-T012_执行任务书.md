## 目标

以 YF Life 官方页面公开引用的产品清单和同域公开 POST API 为证据链，采集各产品/币种的分红实现率，保存原始 API 响应并标准化入库，使真实分红覆盖达到 6 家。

## 验收标准

1. 页面、公开 `ratio.js`、API 端点、请求参数和响应均来自 YF Life 官方域名并有快照/哈希；不使用登录、Cookie 或绕过机制。
2. 产品与币种枚举完整，分页/空数据/失败语义明确；请求数量受控，失败可恢复。
3. 原始 API 响应可追溯；报告年、产品、红利类型、币种/范围、观察期、原始值和标准值无损入库。
4. fixture、幂等、结构漂移、部分失败及真实数据抽样核对通过；全量回归无回退。
