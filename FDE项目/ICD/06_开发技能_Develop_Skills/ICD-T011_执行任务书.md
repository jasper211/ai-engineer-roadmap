## 目标

复用现有 HTML 抓取、快照、标准化写入和全量编排能力，新增 Sun Life、BOC Life 两个直接 HTTP 官方来源的分红实现率解析。执行中确认 YFL 当前数值由官方 POST API 动态加载，不再属于静态 HTML，已拆为 T012，禁止用空容器假装解析成功。

## 允许范围

- ICD 内相关 HTML parser、解析分流、fixture、测试、配置/契约/README、真实快照、数据库及审计证据。
- 只使用注册表已有官方入口；若页面已改版，可经官方页面验证后更新注册表并保留证据。

禁止修改 ICD 外项目、Git 提交、引入浏览器自动化、静默丢弃产品/年度/红利类型，或把非履行率指标混入。

## 验收标准

1. 三家分别保存官方原始快照并验证 HTTP、哈希、字节数和最终 URL。
2. parser 对真实结构有明确锚点与漂移失败语义；支持产品、报告年、保单/发行年、红利类型、原始值及标准比率。
3. Sun Life 的归原红利必须独立映射，不能与周年/终期红利合并。
4. fixture 覆盖正常、不可数值化、结构漂移、幂等与 CLI；既有 T002-T009 无回归。
5. 默认库完成真实抓取解析后，逐家记录产品数、记录数、年份范围、类型分布和抽样官网原文核对；数据库 integrity/FK 通过。
6. `--run-all --no-network` 能处理新增来源，coverage_status 对三家为真实 FULL/PARTIAL，而不是 MISSING。
