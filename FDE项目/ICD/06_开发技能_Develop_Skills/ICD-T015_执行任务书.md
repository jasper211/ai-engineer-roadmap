# ICD-T015 · 只读查询适配器与准确性证据输出

> 执行与审计：Codex  
> 状态：ACCEPTED（Codex 自审）  
> 日期：2026-09-07

## 目标

把已经入库的分红履行率、RBC、覆盖状态和来源证据通过稳定的只读接口提供给 U020 等下游；查询不得修改数据库，并必须能从业务值回溯到官方原始快照。

## 验收标准

1. 提供 Python 只读适配器与 CLI，支持 `fulfillment`、`rbc`、`coverage`、`evidence` 四类查询。
2. 默认业务查询只返回每个自然业务键的最新成功快照版本；可显式请求历史版本，不得因多次抓取重复展示旧值。
3. 支持险企、产品、指标和报告年度过滤；参数化 SQL、有限枚举、limit 上限，禁止拼接任意 SQL。
4. 每条分红/RBC 结果返回 run_id、来源 URL、抓取时间、SHA-256、快照路径和原始值；RBC 返回法律主体原文。
5. SQLite 必须用只读 URI 打开；不存在、损坏或 schema 不兼容时明确失败，不创建空库。
6. 结果必须包含数据质量说明：`normalized_value=null` 表示官网原文不可数值化，不等于零；比率标准值采用小数形式。
7. fixture 测试覆盖只读、最新版本、历史版本、过滤、证据追溯、非法参数和空结果；真实库抽样与官网快照证据一致，全量回归通过。

## 执行回执与自审

- 新增 `tools/icd_query.py`：`ICDClient.open_readonly()` 使用 SQLite `mode=ro`；提供 fulfillment、rbc、coverage、evidence 四类白名单参数化查询。
- Agent CLI 新增 `--query` 及险企、产品、指标、报告年度、历史版本、返回上限、披露类型、run_id 过滤参数。
- 业务结果携带官网原始值、法律主体、run_id、官方 URL、抓取时间、SHA-256 与快照路径；默认按自然业务键仅返回最新成功抓取版本。
- T015 定向测试通过：只读文件哈希不变、不存在的 DB 不会被创建、最新/历史语义、过滤、证据、非法参数、CLI 均通过。
- T002-T015 共 12 套测试脚本全部通过。
- 真实库审计：14 个成功快照逐文件重算 SHA-256，错配 0；13,041 条业务记录全部关联成功抓取；2,557 个可直接按百分号原文复算的数值转换错配 0；自然键重复 0；`integrity_check=ok`、外键违例 0。
- 自审结论：满足验收标准，T015 放行。
