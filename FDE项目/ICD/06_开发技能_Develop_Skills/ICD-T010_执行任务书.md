# ICD-T010 · 可切换的邮件重大决策 Gate

> 执行方：vscode-deepseek  
> 推动与审计：Codex  
> 状态：PAUSED  
> 派发日期：2026-09-04

## 目标

增加 `LOCAL` / `REMOTE_EMAIL` 两种审批模式。进入重大决策 Gate 时，远程模式发送带唯一 Gate 身份的邮件；仅在收到可信、有效、未使用的回复后形成结构化决策。普通工程选择不得发送邮件。

## 安全边界

1. 授权码只允许运行时从 macOS 登录钥匙串 generic-password 服务 `ICD_EMAIL_APPROVAL` 读取；禁止写入代码、配置、环境文件、夹具、日志、异常、命令行、Git diff 或回执。
2. 开发和测试不得读取真实授权码、真实登录或发送邮件；必须 mock 钥匙串、SMTP、IMAP。真实验证由 Codex 审计阶段执行。
3. 账号从钥匙串 account 属性获取，默认发件人和收件人为该账号；日志只可脱敏显示。
4. QQ TLS 参数：SMTP `smtp.qq.com:465`（SMTP_SSL），IMAP `imap.qq.com:993`（IMAP4_SSL）；禁止明文降级或忽略证书验证。
5. 每个 Gate 使用密码学随机的 `gate_id` 与一次性 reply token，带有效期。token 只可出现在 Gate 邮件和权限收紧的本地状态；审计日志不记原值。
6. 回复须同时验证发件人白名单、gate_id、token、有效期、未消费，以及 `In-Reply-To`/`References` 对原始 Message-ID 的线程关联。失败不得推进，重放不得重复消费。

## 功能要求

1. 新建与采集业务隔离的审批模块和 CLI，至少提供 `mode status|local|email`、`gate send`、`gate poll`；默认 `LOCAL`，切换无需改代码。
2. 模式和 Gate 状态在 ICD 受控运行目录原子写入；含 schema_version、mode、状态机、时间、决策和必要邮件元数据。敏感文件 `0600`，目录尽量收紧；损坏状态安全失败。
3. 邮件清楚列出事项、选项、截止时间及严格回复格式：`APPROVE <gate_id> <token>`、`REJECT ...`、`OPTION <编号> ...`；不得将自然语言猜成批准。
4. `gate poll` 只处理未决 Gate 候选回复，不删除邮件；网络、认证或解析失败返回可区分的非零退出码和脱敏错误，不改变 Gate 为通过。
5. 结构化输出区分无决定、批准、拒绝、选择、过期及配置/网络错误。发送成功前不得进入等待态；发送与状态落盘须幂等，避免重复通知。
6. 文档说明开关、发送、轮询、钥匙串弹窗和电脑休眠/关机/断网限制；恢复联网并启动 Codex 后才可续跑。
7. 更新协同协议：邮件只替代重大决策 Gate 通道，不扩大授权，不接受任意命令。
