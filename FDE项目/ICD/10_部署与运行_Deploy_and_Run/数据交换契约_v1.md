# ICD 数据交换契约 v1

## 包结构

- `manifest.json`：契约版本、包 ID、发布状态、数据截至时间、记录数、文件 SHA-256 和消费者规则。
- `fulfillment_ratio.jsonl`：每行一个最新成功分红观测，适合流式读取。
- `rbc_statement.json`：最新成功 RBC 法律主体记录数组。
- `coverage_status.json`：全部险企 × 披露类型的覆盖状态与最近错误。
- `health.json`：发布时完整健康检查结果。

## 稳定语义

- 契约版本为 `1.0.0`；破坏字段语义或删除字段必须升级主版本。
- `normalized_value`、`solvency_ratio` 为小数比率，`1.0=100%`；原始官网值分别保留在 `raw_value`、`solvency_ratio_raw`。
- `null` 不等于零。产品名和法律主体名均保留官网原文，不做未经审定的集团或产品合并。
- `release_status=PARTIAL_COVERAGE` 时消费者必须读取并展示 `coverage_status.json`，不得宣称全市场完整。
- `run_id`、`source_url`、`fetched_at`、`sha256`、`snapshot_path` 共同组成证据链。

## 发布命令

```bash
python3 04_定义Agent_Define_Agent/agents/agent.py --export
```

目录名由契约版本和文件内容哈希生成；相同数据重复导出复用同一目录，内容不一致时拒绝覆盖。
