# ICD · 双模型全自动推进案例复盘

> 案例定位：Codex 负责规划、派发、独立审计和放行；vscode-deepseek 负责实现与返工；Jasper 仅在重大业务决策 Gate 和最终验收介入。  
> 目标：在交付 ICD 的同时，沉淀可复制的非必要人工不介入协同模式。

## 一、当前结论

- 自动闭环可行：任务书 → 执行 → 独立审计 → 返工 → 放行 → 下一任务已连续运行至 T009。
- 人工应只处理不可逆业务口径：T007 法律主体冲突由 Jasper 决策，其余实现和审计均自动完成。
- 质量收益明确：Codex 审计发现并纠正了执行方未识别的法律主体混用，以及 SQLite 回滚与物理快照移动不一致两个关键问题。
- 当前最大效率损耗不是编码，而是冷启动重复读、超长测试输出、任务跨度过大和会话重复派发。

| 阶段 | 结果 | 自动返工/决策 | 主要经验 |

## 三、已发生的效率事件

### E001 · DeepSeek 余额不足

- 影响：T004 启动被 HTTP 402 阻断，自动推进暂停。
- 处理：余额恢复后原任务继续。
- 规则：外部执行器不可用不等于任务失败；记录状态，不重复改代码。

### E002 · T008 重复会话

- 影响：会话句柄不可用后重新派发，同一任务出现既有并行产物，新会话重新检查和合并，增加 token。
- 根因：只依赖进程句柄判断任务是否仍在运行。
- 修正：派发前同时核查会话、任务日志、文件时间和工作区变化；证据不足时不重复派发。

### E003 · 回归输出过量

- 影响：一次回归输出约 559 条成功断言，终端输出重新进入模型上下文。
- 修正：开发期只跑相关测试；最终全回归一次；日志只保留退出码、失败项、断言总数和摘要。

### E004 · 本机 metrics 无数据

- 现象：`deepseek metrics --json --since 24h` 返回 0 条记录，无法反推历史精确 token。
- 处理：不得虚构 token；从后续任务开始记录可取得的时间、会话、命令轮次、测试次数和输出规模。待执行器提供可靠 usage 字段后再补 token/cost。

## 四、后续强制采集指标

每个任务由 Codex 在放行时追加一行指标：

| 字段 | 定义 |
|---|---|
| task_id | 唯一任务编号 |
| dispatch_at / submitted_at / accepted_at | 派发、提交、验收时间 |
| deepseek_sessions | 执行会话数；目标为 1，返工另计 |
| correction_rounds | Codex 退回次数 |
| major_gates | Jasper 介入次数及原因 |
| files_changed | ICD 内变更文件数 |
| focused_tests / full_regressions | 定向测试和全回归次数 |
| test_summary | 退出码、失败数、断言汇总 |
| duplicate_dispatch | 是否发生重复派发 |
| context_rereads | 已知完整文档重复读取次数 |
| elapsed_minutes | 从派发到 ACCEPTED 的墙钟时间 |
| token_input/output/cached | 仅在执行器提供可信 usage 时填写，否则 `unavailable` |
| key_findings | 审计发现和可复用规则 |

## 五、推荐的复制模板

1. 用单独协议固定三方职责、状态机、重大 Gate 和路径边界。
2. 每次只有一个当前任务，任务书必须包含允许范围、禁止项、确定性测试和真实证据。
3. 执行模型只负责实现和一次简明自证；审计模型独立运行关键测试，不复述执行方自审。
4. 普通技术选择自动裁定；只有法律主体、数据口径、不可逆 Schema 或范围变化进入人工 Gate。
5. 每个 ACCEPTED 任务立即生成唯一下一任务；断网/关机依靠日志恢复，不依靠模型记忆。
6. 所有状态、证据、返工原因和指标落盘，使另一台机器或新会话可恢复。
7. 先以质量闭环跑通，再优化 token；不得以节省 token 为由减少真实数据核验或独立审计。

## 六、优化目标

- 同一任务默认 1 个执行会话。
- 普通任务 0 次人工介入；重大 Gate 才请求 Jasper。
- 每个任务最多 1 次最终全量回归；失败后只复跑受影响范围，验收前再全量一次。
- 成功测试输出压缩为不超过 30 行摘要；失败保留必要上下文。
- 不重复通读完整任务历史；使用当前状态摘要和精确文件/行段。
- 对连续三个任务滚动比较耗时、返工轮次和会话数，验证优化是否真实生效。

## 七、最终案例交付物

项目最终验收时同时交付：

- ICD 工程与数据库；
- 完整任务日志和决策 Gate；
- 本案例复盘；
- 分任务效率指标表；
- 可复制的协同协议与任务书模板；
- 已知失败模式、恢复步骤和适用边界。
